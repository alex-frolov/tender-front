# Tender Front — Решения и контекст

**Дата:** 2026-08-17 · **Владелец:** Александр Фролов · **Док 😼**

## Контекст

Tender Platform (пет-проект, `tender`) — API-first e-procurement engine на Symfony 8.1 / PHP 8.5,
82 пути OpenAPI, 62 схемы. Фронта нет — сейчас API «демонстрируется» через Swagger UI.
Нужен веб-клиент для демонстрации (что сильнее для портфолио и консалтинга B2B).

## Принятые решения

1. **Отдельный репозиторий `tender-front`** — в `channels/github/repositories/`, рядом с `tender`.
   Фронт — не основное в бренде, поэтому стек выбран прагматичный, с максимальной скоростью разработки соло.
2. **Стек:** React 19 + Vite + TypeScript + TanStack Query + React Router + Tailwind 4 + shadcn/ui.
   (TanStack Query идеально ложится на REST-кэш/инвалидацию; shadcn/ui режет время на UI.)
3. **Контракт:** единственный источник — `tender/app/public/openapi.yaml` (EN-версия).
   Типы генерируются `openapi-typescript` → `src/api/schema.d.ts`. Никакого ручного дублирования типов.
4. **Деплой:** отдельный docker-образ (nginx + статика) + прокси `/api` → API-контейнер в одной сети.
   Один домен ⇒ без CORS, один TLS. Фронт обновляется независимо от API.
5. **Язык UI:** русский (аудитория демо).

## Структура репозитория

- `app/` — корень git-репозитория `tender-front` (всё, что попадает в GitHub).
- Вне `app/` (в корне каталога проекта) — служебные файлы: `memory/` (заметки, контекст) и пр. В git они не попадают.
